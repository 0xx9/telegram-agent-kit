## العربية

**Telegram Agent Kit** — مجموعة Skills جاهزة لـ Cursor تساعدك تبني بوتات Telegram احترافية بدون تسريب tokens أو أخطاء webhook.

### تثبيت سريع

```bash
git clone https://github.com/0xx9/telegram-agent-kit.git
cd telegram-agent-kit
./scripts/install.sh
```

### ماذا تحصل؟

- 6 Agent Skills (إعداد، webhook، دفع، أمان، aiogram، Telethon)
- قواعد أمان دائمة لـ Cursor
- قوالب جاهزة للبدء

### أوامر جرّبها في Cursor

```
ابني بوت تحقق join request لقناتي الخاصة باستخدام aiogram
```

```
راجع كود Telethon للتأكد من عدم تسريب session files
```
